# AgroPainel

O sul do Maranhão é uma das regiões que mais cresce no agronegócio brasileiro, com soja, milho e algodão em Balsas, Tasso Fragoso, Sambaíba e nos
municípios vizinhos. Um produtor de médio porte acompanha dezenas de talhões, registra cada operação no caderno e consulta o clima em três
aplicativos diferentes antes de decidir se pulveriza hoje.
O AgroPainel junta tudo isso numa aplicação só. O produtor cadastra os talhões, registra as operações de cada um, acompanha em que fase cada lavoura
está e consulta o clima do município, com um indicador que diz se as condições de agora são boas para pulverizar.
